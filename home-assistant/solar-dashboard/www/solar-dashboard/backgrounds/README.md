# Background images for the solar dashboard
#
# Place these JPEG files in this folder on your Home Assistant host:
#   /config/www/solar-dashboard/backgrounds/
#
# Required filenames (must match sensor.solar_dashboard_background states):
#   clear.jpg          — sunny day
#   cloudy.jpg         — partly cloudy
#   covered.jpg        — overcast / rain / fog
#   very_covered.jpg   — storm / heavy rain (optional duplicate of covered.jpg)
#   night.jpg          — after sunset
#
# Tips for matching the reference design:
# - Use 1920×1080 (16:9) images for wall tablets.
# - Keep the house, panels, pylon, and dashed flow arrows in the SAME position
#   on every variant so button-card overlays stay aligned.
# - The original creator used a custom landscape based on art by Zia Ul Hassan;
#   commission or source similar stock art — do not redistribute copyrighted work.
#
# Until your final art is ready, solid-color placeholders are fine for layout tuning.
